# User Guide

## Starting the toolkit
Run `python main.py` from the project directory. Select a number from the main menu.

## Date and Time
1. Display the current date/time.
2. Enter two dates in `YYYY-MM-DD` format to calculate their day difference.
3. Enter a date and a `strftime` format such as `%d-%m-%Y`.
4. Press Enter to start and stop the stopwatch.
5. Enter the number of seconds for the countdown.
6. Return to the main menu.

## Mathematical Operations
Choose factorial, compound interest, trigonometric values, circle/rectangle/triangle area, or kilometre-to-mile conversion. Enter numeric values when prompted.

## Random Data
Generate a random integer, a list, a password, an OTP, a sample from comma-separated values, or a coin toss.

## UUID
Choose option 4 on the main menu to generate a UUID version 4 identifier.

## File Operations
Choose option 5. Enter a filename such as `notes.txt`. Create the file before reading it. Write replaces existing content; append adds content at the end.

## Explore module attributes
Choose option 6 and enter one of: `math`, `datetime`, `time`, `random`, `uuid`, `file_operations`, or `math_utils`. The toolkit displays the names returned by `dir()`.

## Exit
Choose option 7 on the main menu.
